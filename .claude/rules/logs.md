# Logs are append-only

- New entries go at the top, dated `YYYY-MM-DD`.
- Never edit or delete a past entry. If something was wrong, add a new entry
  correcting it — the fact that I recorded it wrong is itself information.
- Don't summarize or condense old entries to save space. If a log gets long,
  start a new file (`log-2027.md`) and leave the old one intact.
- Record what actually happened, not what was planned. If I skipped
  something, the log says so.

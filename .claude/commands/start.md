Get oriented before we start. Don't change any files yet.

`PROJECT_STATE.md` is already in your context from the SessionStart hook, so
don't re-read it. Read these:

1. @docs/decisions/INDEX.md
2. Any decision record from that index that touches the current focus — only
   those, not the whole directory
3. @docs/working/open-questions.md

Then tell me, briefly:

- What you understand the current focus to be
- Which past decisions constrain it
- Anything that looks stale or contradicts itself
- Any open question that blocks the current focus

Then stop and wait for me.
